# High Five-ligan 2026

Ställningen i Redheads säljtävling för High Five-butikerna, 1 okt – 31 dec 2026.
Sidan är lösenordsskyddad: butiksdatan är AES-256-GCM-krypterad och nyckeln
härleds ur lösenordet. Utan det finns ingenting att läsa i källkoden.

Byggs från `~/Redhead-team/kampanj-verktyg/high-five-ligan-2026/` — redigera aldrig
index.html här för hand.
